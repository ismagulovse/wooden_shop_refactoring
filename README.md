# WoodenShop

Учебный интернет-магазин деревянной мебели. Покупатель может просматривать каталог, добавлять товары в избранное и корзину, оформлять заказы и управлять профилем. В административной части можно работать с товарами, категориями, заказами и пользователями. Репозиторий используется для лабораторной работы по рефакторингу проекта.

## Стек

- **Серверная часть:** PHP, собственные маршрутизатор и MVC-структура.
- **База данных:** MySQL, доступ через PDO.
- **Интерфейс:** HTML, CSS и JavaScript без фронтенд-фреймворка.
- **Локальная разработка:** OSPanel.

## Структура проекта

Основная логика магазина находится в папках `controllers/`, `models/` и `views/`; маршруты — в `routes/`, расчёт стоимости заказа и дополнительных услуг — в `services/`, административная часть — в `admin/`. Исходная схема базы данных находится в `database.sql`, а изменения схемы — в `migrations/`.

Соответствие названий в диаграмме и классах кода приведено в [документации к UML](docs/uml/README.md).
